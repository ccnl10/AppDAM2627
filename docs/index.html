Cómo usar el proyecto

Necesitas Android Studio (versión estable). SDK mínimo: API 24.

  1. Clona el repositorio 
    git clone https://github.com/USUARIO/MyAppDam1.git
  2. Ábrelo en Android Studio File > Open y espera a que termine la sincronización de Gradle.
  3. Mira el ejemplo con la vista previa Abre el fichero y usa el panel Split o Design para ver los @Preview.
  4. Lánzalo desde MainActivity Llama al composable dentro del Scaffold, pasándole el padding: 
    Scaffold(modifier = Modifier.fillMaxSize()) { innerPadding ->
    NombreDelEjemplo(modifier = Modifier.padding(innerPadding))
}
  5. Actualiza después de cada clase 
    git pull
    Si se ha añadido alguna librería nueva, sincroniza Gradle otra vez.
